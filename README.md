# plasmofit-test

Driver scripts and saved fits for the `plasmofit` package. Not a package itself.

- `_scripts/` — data prep, cluster fitting, analysis, and a parameter-recovery check
- `_data/` — the cleaned Wockner data and saved fits

See `claude/CLAUDE.md` for how the scripts fit together, why the current model
configuration is what it is, and what the `_data/` file naming means. Notes on
the package itself (model internals, optimizations) live separately, in
`plasmofit/claude/`.
